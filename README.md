# Smart Trolley using PIC16F887

## Project Description
Smart shopping trolley using PIC16F887, RFID and LCD for automatic product identification and bill calculation.

## Hardware Used
- PIC16F887
- RFID Module
- 16x2 LCD
- Push Buttons

## Software Used
- MPLAB X IDE
- Embedded C
- Proteus

## Working
The RFID module reads the product tag and sends the product information to the PIC16F887.
The PIC processes the product information and displays the product details and bill on the LCD.
